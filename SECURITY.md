# Security policy

EveryLock is an isolated availability-research lab. Run it only against synthetic accounts on loopback (`127.0.0.1`, `localhost`, or `::1`).

Do not use the project to enumerate real accounts, automate authentication against third-party systems, or induce real account lockouts. Report observations through coordinated disclosure and never include account identifiers, passwords, cookies, or session values in issues.

The repository demonstrates a policy risk; it does not establish that any named production system is vulnerable.
